# EventEase – Blazor Web Application

## Project Description

EventEase is a web application designed to help users browse upcoming events, view event details, and register for events.

## Features

- Display a list of upcoming events.
- Show event details, including the date, location, and description.
- Provide a registration page where users can enter their name and email address.
- Navigate between the event list, details, and registration pages.

## Technologies Used

- C#
- Blazor
- .NET
- HTML
- Visual Studio Code

## Running the Application

1. Install the .NET SDK.
2. Open the project folder in Visual Studio Code.
3. Open a terminal in the project directory.
4. Run `dotnet run`.
5. Open the local URL shown in the terminal in your browser.

## Project Status

This project is a learning exercise focused on building a basic event management application with Blazor.
